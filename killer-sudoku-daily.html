How to play Killer Sudoku

Killer Sudoku is Sudoku with the givens removed. Instead of pre-filled numbers, the grid is divided into dotted cages — each cage shows a target sum in its top-left corner. Fill every cell with a digit from 1 to 9 so the standard Sudoku rules hold AND every cage adds up to its target. No digit may repeat within a cage.

THE RULES

  1. Every row must contain each digit 1–9 exactly once.
  2. Every column must contain each digit 1–9 exactly once.
  3. Every 3×3 box must contain each digit 1–9 exactly once.
  4. The digits in each cage must sum to that cage's clue. No digit repeats inside a cage.

BEGINNER STRATEGY

  • Start with the smallest cages. A 2-cell cage summing to 3 can only be {1, 2} — and a cage summing to 17 can only be {8, 9}. These "locked" cages hand you digits for free.
  • Use the 45 rule. Any complete row, column, or 3×3 box sums to 45. If cages inside a region are fully contained, their totals must add to 45 — meaning any cage that straddles the region boundary lets you calculate the "outie" digit exactly.
  • Eliminate with Sudoku rules. Once a cage's possible digit sets are narrowed down, treat them like naked or hidden candidates — the same row/column/box logic from regular Sudoku still applies.
  • Never repeat in a cage. Even if a digit is legal in a cell by Sudoku rules, drop it as a candidate if it already appears elsewhere in the same cage.
