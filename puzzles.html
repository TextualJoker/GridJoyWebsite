EXPLORE · 18 PUZZLE TYPES · UP TO 5 TIERS

Puzzles.

Eighteen number puzzle types, grouped by how they make you think. Tap a card for rules, strategy, and a worked sample.

SUDOKU FAMILY

Latin-square puzzles — every row and column holds each digit once. Most start here.

  • Sudoku →

    9×9 grid, three rules, infinite variations. The genre's anchor.

  • Killer Sudoku →

    Sudoku rules plus cage sums. Magic-sum thinking on a familiar grid.

  • Calcudoku →

    Latin square + any-operator cages. No 3×3 box rule.

  • Inequality (Futoshiki) →

    Latin square with < and > clues between neighbouring cells.

  • Skyscraper →

    Latin square plus edge clues — count the visible buildings.

ARITHMETIC

Sum and combination puzzles. The clue is a number; the deduction is which digits make it.

  • Kakuro →

    Number crossword — each run sums to its clue, no digit repeats.

  • Number Crossword →

    Across-only arithmetic clues. Evaluate, then place.

  • Sumplete →

    Delete cells until every row and column hits its target sum.

  • Number Blocks →

    Fill empty cells with digits so rows and columns hit their sums.

  • Countdown →

    Six numbers, four operators, one target. Channel-4 numbers round.

PATH & MAZE

Find the route from start to finish — by jumping the numbers, threading the walls, or filling one chain.

  • Number Maze →

    Every cell is a jump distance — hop from start to finish.

  • Square Maze →

    Thread open passages corner to corner. Walls block — no numbers.

  • Circular Maze →

    Route through concentric rings — inward, outward, around. No numbers.

  • Hex Mazes →

    Flat-top hex grid — up to six exits per cell. Thread the walls, no numbers.

  • Starlink (Hidato) →

    Trace 1 through N² across adjacent (including diagonal) cells.

SHADING & SPATIAL

No new digits — work with what's there. Topology, parity, and constraint logic.

  • Hitori →

    Shade cells so no digit repeats in any row or column.

  • Takuzu (Binairo) →

    Binary grid — balance 0s and 1s, no three in a row.

  • Shikaku →

    Divide the grid into rectangles, one numbered cell per rectangle.
