Sudoku

The classic 9x9 logic grid

Sudoku is the classic number-placement puzzle played on a 9×9 grid.

OBJECTIVE

Fill every empty cell so each row, column, and 3×3 box contains the digits 1–9 exactly once.

RULES

  1. 1.Each row must contain 1–9 with no repeats.
  2. 2.Each column must contain 1–9 with no repeats.
  3. 3.Each bold-bordered 3×3 box must contain 1–9 with no repeats.
  4. 4.Pre-filled (clue) cells cannot be changed.

TIPS

  • Start with rows, columns, or boxes that already have many numbers filled in.
  • Use pencil notes to track possible candidates for tricky cells.
  • Look for "naked singles" — cells where only one number is possible.

FREQUENTLY ASKED

Questions about GridJoy

What is GridJoy?
GridJoy is a free Android puzzle game featuring 18 number puzzle types — including Sudoku, Calcudoku, Kakuro, Killer Sudoku, and Hex Mazes. It comes with a ghost mascot companion that levels up as you solve puzzles, earn XP, and unlock cosmetics.
Is GridJoy free to play?
Yes. GridJoy is free to download and play, with no in-app purchases at all. All 18 puzzle types are unlocked from the start — no paywalls, no energy bars, and it's 100% ad-free: no banners, no interstitials, no rewarded video, anywhere. Every hint is free. If you'd like to support a one-person project you can buy the dev a coffee, but it's entirely optional and unlocks nothing.
Is GridJoy available on iPhone or iPad?
GridJoy is currently available on Android only. An iOS version is not available at this time. Download it free from the Google Play Store.
